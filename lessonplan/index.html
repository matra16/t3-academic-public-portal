แผนการจัดการเรียนรู้

OVERVIEW

วางระบบงานวิชาการให้ต่อเนื่อง

เตรียมกระบวนการทำแผนการสอน ตรวจทาน และบันทึกหลังสอน โดยคงสิทธิ์และอำนาจอนุมัติตามผู้รับผิดชอบจริง

01

จัดทำและส่งแผน

เตรียมการจัดส่งเอกสารและติดตามสถานะของแผนเมื่อระบบส่วนงานภายในเปิดใช้งาน

02

ตรวจทานและส่งกลับ

กระบวนการตรวจทาน ข้อเสนอแนะ และส่งกลับแก้ไขตามสิทธิ์ของผู้ตรวจและผู้รับผิดชอบ

03

บันทึกหลังสอนและรายงาน

เตรียมบันทึกผลการสอนและจัดทำรายงานประกอบหลักฐานทางวิชาการ

สถานะการให้บริการ

  • Release B — ระบบทดสอบสำหรับผู้มีสิทธิ์ยังไม่เปิดใช้งาน
  • Release C — ระบบงานครบวงจรยังไม่เปิดใช้งาน
ประกาศการเข้าถึง

หน้านี้เป็นหน้าแนะนำระบบเท่านั้น ยังไม่มีระบบล็อกอินหรือการรับไฟล์แผนการสอนและข้อมูลบุคลากร/นักเรียน
