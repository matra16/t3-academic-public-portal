📌 ใช้เครื่องร่วมกับคนอื่น?

กดล้างข้อมูลก่อนส่งเครื่องต่อให้เพื่อน เพื่อไม่ให้คนอื่นเห็นชื่อเล่นหรือโน้ตของเรา

Profile V6 เก็บในเบราว์เซอร์เครื่องนี้เท่านั้น ยังไม่รองรับกู้คืนข้ามเครื่องหรือข้อมูลประเมินรายบุคคล

🔗 QR และลิงก์เข้าห้อง

🔗 ลิงก์หน้าแรกของระบบห้องเรียน

หน้าเว็บไซต์และ QR รายห้องใช้ GitHub Pages โดยตรง ไม่ผ่านบริการย่อลิงก์ภายนอก และไม่มีรหัสประจำตัวนักเรียนใน URL
