ACCESS CONTROL

สิทธิ์และความปลอดภัย

ขอบเขตจริงของระบบ V9: Public Workspace ไม่ใช่ Protected School Admin

GitHub ACLเปลี่ยนค่าจริงผ่าน GitHub EditorGitHub เป็นผู้ตรวจว่า Account มีสิทธิ์ Commit เข้า repo
Public UIผู้เยี่ยมชมดู Admin Workspace ได้หน้าเว็บไม่มี Token, Credential, ข้อมูลนักเรียนหรือ API เขียนค่า
ยังไม่มีSchool Admin SSO / RBAC / Student impersonationต้องมี backend ส่วนตัวและการอนุมัติเจ้าของระบบก่อน

การควบคุมข้อมูลนักเรียนและ AI

AI จริง การส่งงานหลายกลุ่ม การติดตามรายบุคคล การประเมินและสิทธิ์ดูสื่อเด็กยังไม่เปิดบน Public GitHub Pages
